| 变量 | 类型 | 初始值 | 影响路径 |

| press_start_delay | 秒 | 0 | 选择点1(A:+5, B:+12) |

| aed_protocol_clean | bool | null | AED流程完成后→true |

| family_trust | -2~3 | 0 | 选择点5(A:+1→+2, B:-1) |

## 坏结局触发条件

```
触发路径: choice_1:B → choice_2:B → choice_5:B
即: 先举起手机(延误12秒) → 再等22秒 → 家属冲突时停下解释(中断24秒)

condition: false_wait_penalty > 0 && compression_interrupt_time >= 24
→ 跳转到 bad_ending "迟到的代价"
→ 然后正常进入 aed_map → chapter_review
```

## 交互模块类型

| 类型 | 绑定场景 | 触发方式 |
|------|----------|----------|
| cpr | cpr_rhythm | 空格/点击交替按压，完成30次后进入下一场景 |
| assign | name_witness | 点击3张证人卡片，全部点完进入下一场景 |
| takeover | let_others | 3秒倒计时内点击"交接"按钮 |
| aed | aed_protocol_start/clear_space/execute | 点击/AED操作按钮，按步骤推进 |
| review | chapter_review | 自动显示复盘面板 |
